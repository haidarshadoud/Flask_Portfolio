# AI Portfolio

A personal portfolio website built with Python and Flask to showcase my projects and technical skills in Artificial Intelligence.

## Features

- Personal introduction and technical skills
- Dynamic project cards
- Project descriptions and technology stacks
- Project images and GitHub links
- Responsive design for different screen sizes
- Contact section

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- Jinja2
- Git and GitHub


















## Installation and Setup

### 1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL
### 2. Navigate to the project directory

cd Flask_Portfolio
### 3. Create a virtual environment

python -m venv .venv
### 4. Activate the virtual environment on Windows

.venv\Scripts\activate
### 5. Install the required packages

pip install -r requirements.txt
### 6. Run the application

python app.py
### 7. Open the website

Visit the following address in your browser:

http://127.0.0.1:5000
